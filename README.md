# 🚀 Scientific Calculator Web App

A fully responsive **Scientific Calculator** built using **HTML, CSS, and JavaScript**. This application performs both basic arithmetic operations and advanced mathematical calculations through a clean and user-friendly interface.

---

## ✨ Features

### 🔢 Basic Operations
- Addition (+)  
- Subtraction (−)  
- Multiplication (×)  
- Division (÷)  
- Percentage (%)  

### 📐 Scientific Functions
- Trigonometric: `sin`, `cos`, `tan`  
- Logarithmic: `log`, `ln`  
- Power & Roots: `xʸ`, `√`  
- Constant: `π`  

### ⚡ Functionality
- Real-time calculation display  
- Instant results  
- Clear (C) and delete (⌫) buttons  
- Error handling for invalid input  

### 🎨 UI & Design
- Clean and modern interface  
- Smooth hover effects  
- Responsive layout (mobile, tablet, desktop)  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3 (Grid & Flexbox)  
- JavaScript (ES6)  

---

## 📌 How It Works

Users enter expressions using calculator buttons.  
JavaScript processes the input and displays results instantly.  
Scientific operations are handled using built-in Math functions.

---

## ⚠️ Note

This project uses the `eval()` function for calculations.  
It is suitable for learning but not recommended for production due to security concerns.
